# Mafia MVP
[Русский](README.md) · [English](README.en.md)

**GitHub About / English:** A school-day idea, now an early MVP: testing how Mafia should play over the network. The aim is a working game people can sit down and play together.
**Описание GitHub / Русский:** Мечта со школы, сейчас ранний MVP: проверяю, как должна играться «Мафия» по сети. Цель — рабочий проект, в который можно сесть вместе.

Ещё в школе хотелось сделать «Мафию», в которую играют вместе по сети. Сейчас это ранний MVP: гипотезы проверяются на живом прототипе. Цель — довести его до рабочего проекта.

Локальная браузерная версия «Мафии» для подбора игровых механик. Сервер, роли комнат и сохранённые игры находятся в этой папке.

## Запуск

Нужен Node.js 22.13 или новее (для встроенного модуля SQLite). Из папки проекта выполните:

```powershell
npm start
```

После запуска откройте адрес, который напечатал сервер; обычно это <http://localhost:4444>. Сервер не открывает браузер сам.

Порт задаётся переменной окружения `PORT`. Например, в PowerShell:

```powershell
$env:PORT = '3100'
npm start
```

После остановки сервера переменная будет действовать только в этом окне PowerShell. Чтобы выбрать случайный свободный порт, укажите `PORT=0`; фактический адрес сервер напечатает при запуске.

При первом запуске создайте аккаунт администратора на стартовом экране: задайте логин, пароль и электронную почту. Пока администратор не создан, обычный вход и регистрация недоступны; пароля по умолчанию нет. После первичной настройки следующие аккаунты получают права игроков. Панель показывает комнаты и дневные чаты, позволяет кикать и банить игроков, снимать баны, просматривать аккаунты и журнал действий. Там можно менять уровни «Мирный» и «Мафия» (0–100), видимость уровней, сбрасывать пароли других аккаунтов и удалять их. Свой пароль администратора восстанавливается по электронной почте. Лёгкий юмор ведущего включается там же и выключен по умолчанию.

Для восстановления пароля заполните в админке настройки SMTP: сервер, порт, тип шифрования (без шифрования, SSL/TLS или STARTTLS), логин и пароль, адрес отправителя. Сохраните настройки и отправьте тестовое письмо. Сброс приходит одноразовой ссылкой на почту аккаунта; ссылка действует 30 минут. Почта обычному игроку необязательна, но без неё сброс недоступен. Настройки SMTP, включая пароль, хранятся в SQLite в папке `data/` или в Docker томе.

В админке также настраивается показ роли выбывшего: после ночного убийства — всей мафии, только мафиози, голосовавшим за жертву, либо никому; после исключения голосованием — всему городу либо никому. По умолчанию новые раскрытия выключены. Роль показывается личной карточкой только разрешённым игрокам.

Для быстрой пробы на одном компьютере войдите администратором, создайте комнату и откройте «АДМИНКА». Отметьте характеры ботов, затем в карточке комнаты выберите «ЗАПОЛНИТЬ ДО 6», «ЗАПОЛНИТЬ ДО 10» или «ЗАПОЛНИТЬ ДО 20» — размер считается вместе с вами и уже вошедшими игроками. Во время ожидания комнату можно открыть кнопкой «АДМИНКА» прямо с игрового экрана, не покидая лобби. Автоматически комната по умолчанию ждёт людей минуту, затем добавляет ботов до минимума и отсчитывает ещё минуту до старта. Отключить автодобор и изменить оба времени можно в админке; это применяется и к открытым комнатам. Роль игрока показана карточкой: своя — сразу, чужие — после финала; на выбывшей раскрытой карточке есть знак смерти. Боты случайно выбирают ночные действия и голоса, обсуждают подозреваемых, версии комиссара и доктора, учитывают собственную команду и выступают по очереди. Комиссар опирается на результат ночной проверки, мафия ночью выбирает только городских игроков. Настроенные характеры случайно распределяются между добавленными ботами: добрый, шутник, резкий, хаотичный и мягкий; если снять все галочки, боты будут говорить нейтрально. Диалоги собираются из шаблонов и игровых фактов, это не полноценный ИИ. Кнопки добавления доступны только администратору и только до старта партии. Если нужны настоящие люди, откройте сайт в отдельных профилях браузера и зарегистрируйте игроков с разными логинами. Пароль может быть длиной от 1 до 128 символов. Один аккаунт может занимать только одно место в активной партии. Минимум — 6 игроков. Для игры на нескольких устройствах одной локальной сети используйте IP-адрес компьютера с сервером и тот же порт. Данные игр и аккаунтов сохраняются в папке `data/`.

На Windows сервер можно запустить двойным щелчком по `start.bat`, а остановить — по `stop.bat`. Батник остановки завершает только сервер этого проекта, запущенный через `start.bat`.

### Linux

На Linux с Node.js 22.13+ (для встроенного модуля SQLite) выдайте скриптам право на запуск и используйте:

```sh
chmod +x start-linux.sh stop-linux.sh
./start-linux.sh
./stop-linux.sh
```

Сервер работает в фоне; вывод сохраняется в `data/server.log`. Скрипт остановки сверяет PID с путём `server.js` проекта перед завершением процесса. SQLite-база находится в `data/mafia.sqlite`.

### Резервная копия SQLite

Перед копированием базы остановите локальный сервер, затем выполните:

```powershell
npm run backup
npm run restore -- data/backups/mafia-YYYY-MM-DDTHH-MM-SS-sssZ.sqlite
```

Копии создаются в `data/backups/`; восстановление автоматически оставляет рядом копию текущей базы. Для резервной копии запущенного Docker-сервера используйте `docker compose exec mafia node backup-db.js /app/data/backups/manual.sqlite` (затем скопируйте файл через `docker cp`).

Для автоматического развёртывания можно задать необязательные `MAFIA_ADMIN_USERNAME` и `MAFIA_ADMIN_PASSWORD`; обычно проще создать администратора в браузере. Перед обновлением остановите контейнер, сохраните резервную копию тома, затем выполните `docker compose pull` и `docker compose up -d`; для локально собранного образа используйте `docker compose up -d --build`.

Для отдельной тестовой установки, не использующей обычные данные и порт игры, есть `compose.review.yaml`. Скопируйте `.env.review.example` в `.env.review` и выполните `docker compose --env-file .env.review -p mafia-review -f compose.review.yaml up -d --build`. Откройте <http://localhost:4445>. Новая база попросит создать администратора; существующий том сохраняет уже созданный аккаунт. Она использует отдельный постоянный том `mafia-review_mafia-review-data`; не запускайте `down -v`, если хотите сохранить эту тестовую базу.

### Уровни и одноразовые бонусы

Шкалы растут до 100. При 100-м уровне соответствующей шкалы в лобби до старта появляется выбор города или мафии; если выбранная команда заполнена, случайный игрок с обычной ролью меняется командой, уникальные роли сохраняются. Предметы за уровни 10/40/70 добавляют 30 секунд свободного обсуждения, за 20/50/80 дают двойной дневной голос, за 30/60/90 скрывают команду от одной ночной проверки. Предметы копятся, игрок выбирает момент применения; автоматическую выдачу и интервал настраивает администратор. Для безопасного плейтеста выдача выключена по умолчанию.

## Проверки

Запустить автоматические проверки игровых правил можно командой:

```powershell
npm test
```

Тесты используют встроенный test runner Node.js и не требуют установки зависимостей. Баланс состава проверяется для каждого размера от 6 до 20 игроков, а API-тесты проходят партии и действия на серверах с изолированным временным хранилищем.

## Правила MVP

Краткая справка встроена в интерфейс: нажмите «СПРАВКА» в верхней панели на главном экране или во время партии. Полный журнал игровых решений и подробные правила ведутся в [GAME_DESIGN.md](GAME_DESIGN.md); справка и документация обновляются вместе с изменением механик.

- Регистрация и вход по уникальному логину/паролю. Вход запоминается на этом браузере; учётные данные хранятся в локальных файлах `data/`, пароль — в виде хэша.
- В профиле показываются две шкалы «Мирный» и «Мафия» от 0 до 100. После завершения партии игрок получает +1 к шкале своей команды, победители получают ещё +1; добровольный выход из партии до её окончания исключает награду.
- От 6 до 20 играющих; ведущий системный и не занимает место.
- По умолчанию комната ждёт людей 60 секунд, затем добирает ботами до 6 игроков и ждёт ещё 60 секунд до старта. В админке можно выключить автодобор, изменить оба времени; настройки применяются к комнатам в ожидании.
- Роли: мафия (один игрок на каждые четыре участника, минимум один), комиссар, мирные жители; с 8 игроков появляется доктор. В тестовой комнате с 10 игроков администратор может включить мэра и дона; маньяк отложен.
- Ночью чата нет: мафия тайно выбирает цель, комиссар проверяет игрока, доктор защищает другого игрока. Защита разрешается до убийства; проверка проходит независимо.
- Днём: 3 минуты свободного обсуждения, затем выступления по очереди, затем голосование. Ничья ведёт к переголосованию между лидерами; повторная ничья никого не исключает.
- Таймеры MVP по умолчанию: ожидание людей — 60 секунд, отсчёт после набора — 60 секунд, ночь — 90 секунд, выступление — 30 секунд на игрока, голосование — 60 секунд, переголос — 30 секунд. Время набора и старта настраивается в админке.
- Статус «в сети» обновляется запросами комнаты; если браузер не обращался к серверу 5 секунд, игрок отображается отключённым. После возвращения в браузер его сессия и место в партии восстанавливаются.
- При первом запуске первый аккаунт получает права администратора; последующие регистрации — права игрока. Администратор указывает почту. Обычным игрокам почта необязательна; без неё восстановление пароля недоступно. Пароли хранятся как хэши. Настройки SMTP хранятся в локальной SQLite базе.
- Администраторский кик из активной игры помечает игрока выбывшим, но не лишает его прогресса за партию. Нельзя кикать или банить из уже завершённой комнаты.
- Город побеждает, когда мафии не осталось. Мафия побеждает, когда её становится не меньше, чем остальных игроков.
- Это прототип для локального тестирования; аккаунты и игровой процесс не рассчитаны на публикацию в интернете или защиту от людей, имеющих доступ к файлам проекта.
- Используется встроенный SQLite из Node.js 22.13+. При первом запуске JSON-данные автоматически мигрируют в `data/mafia.sqlite`; JSON остаются исходными копиями.
