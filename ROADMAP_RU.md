# План создания Mafia MVP

Цель: локальная браузерная игра, запускаемая из папки проекта. План поэтапный: каждый этап заканчивается работающим результатом, который можно открыть в браузере и обсудить. Новые идеи сверяем с `GAME_DESIGN.md`, задачи отмечаем в `TODO_IDEAS_RU.md`.

- [x] Согласовать накопление одноразовых бонусов и переключаемую администратором периодичность выдачи; начальное значение — раз в неделю.
- [x] Согласовать роль мэра и дона для тестовых составов от 10 игроков; маньяка оставить в заметках.
- [x] Согласовать раскрытие ролей выбывших только в тестовой комнате, включаемой администратором.
- [ ] Уточнить технические границы интервала бонусов и календарную/относительную точку его отсчёта.

**Результат:** короткий утверждённый набор правил без конфликтующих значений в коде и документации.

- [x] Обработать выход, переподключение и истечение таймера без минимального состава.

**Результат:** группа собирается и автоматически начинает игру без отдельного игрока-ведущего.

- [x] Случайно раздавать базовые роли внутри команд; игрок видит только свою роль и информацию о союзниках-мафиози.

- [x] Реализовать проверки победы после каждого выбытия.
- [x] Сделать сервер единственным источником истины для ходов и исхода.

**Результат:** сыгрывается полная партия на базовых ролях от старта до победы.

## Этап 6. День, чат и голосование

- [x] Согласовать цикл: 3 минуты свободного обсуждения → очередь выступлений → голосование.
- [x] Реализовать дневной чат и таймер на 3 минуты.
- [x] Закрыть чат после таймера и провести выступления живых игроков по очереди.
- [x] Установить выступление до 30 секунд и пропускать вышедшего игрока в очереди.
- [x] Провести голосование с возможностью изменить выбор до окончания таймера.
- [x] Переголосовать между лидерами при ничьей; при повторной ничьей никого не исключать.
- [x] Завершать этап автоматически после голосов всех игроков или таймера.

**Результат:** дневной этап полностью управляется интерфейсом и системным ведущим.

## Этап 8. Прогрессия и периодические бонусы

- [x] Реализовать автоматическую случайную выдачу одного предмета из пула доступных десятков обоих уровней после истечения настраиваемого интервала; настройка выключена по умолчанию.
- [x] Добавить инвентарь одноразовых бонусов: хранить до применения, разрешить накопление.
- [ ] Реализовать бонусы постепенно, начиная с самых безопасных.
- [ ] На уровне 100 дать выбрать одну команду (при двух максимальных уровнях — выбрать одну), сохранив случайную роль внутри команды.
- [ ] При нехватке мест случайно перевести игрока без уникальной роли в другую команду и проверить перераспределённый состав.

**Результат:** прогресс влияет на игру только через утверждённые ограниченные умения и выбор команды.

## Предлагаемый порядок старта

Основной вертикальный срез, аккаунты, SQLite, базовая локальная админка, тестовые роли, эффекты бонусов и выбор стороны на 100-м уровне реализованы. API-сценарии покрывают партии на 6/10/20 местах; осталось визуально пройти их в обычном Chrome/Edge и уточнить баланс после наблюдения за поведением игроков.

Мэр и дон включаются только в тестовых составах от 10 игроков; маньяк остаётся в заметках. Бонусный инвентарь накапливается и выдаётся по настройке админки; предметы применяются игроком в подходящей фазе.
